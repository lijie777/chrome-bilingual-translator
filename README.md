# 网页双语翻译

一个 Chrome 插件，用 Chrome 自带的内置翻译（Translator API）把网页翻成**双语对照**：每段原文下面插入译文。翻译在本机离线完成，免费，不需要 API Key，网页内容也不会发到任何服务器。

## 功能

- **双语对照**：译文插在原文下方，左边有一条蓝色竖线，原文保持不动。
- **三种触发方式**：点工具栏图标、快捷键 `Alt+T`、网页右键菜单「翻译此页 / 显示原文」。
- **一键切换**：再触发一次隐藏译文只看原文，再触发一次又显示出来。
- **可选目标语言**：在插件弹窗里选，支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、意大利语、葡萄牙语、俄语。
- **按需翻译**：只翻译滚动到附近的段落，长页面也不卡。
- **自动跳过**：已经是目标语言的段落、代码块、输入框不会被翻译。

## 环境要求

- 电脑版 Chrome **138 或更新版本**（内置翻译从 138 开始提供）。
- 第一次翻译某个语言对（比如英语 → 中文）时，Chrome 需要下载语言包，要联网；之后离线可用。

## 安装

插件还没有上架 Chrome 应用商店，需要手动加载：

1. 下载本仓库（`Code` → `Download ZIP` 然后解压，或者 `git clone`）。
2. Chrome 地址栏打开 `chrome://extensions`，打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的文件夹（就是 `manifest.json` 所在的那一层）。
4. 可选：点工具栏的拼图图标，把「网页双语翻译」固定到工具栏。

> 插件是直接从这个文件夹加载的，装好后不要删除或移动它。

## 使用

1. 打开一个外语网页。
2. 点插件图标选好目标语言，然后点「翻译此页 / 显示原文」；或者直接按 `Alt+T`、右键选菜单。
3. 第一次使用某个语言对时，页面右上角可能会出现「下载并翻译」按钮，点一下开始下载语言包。Chrome 规定下载必须由用户在网页上点击触发，快捷键和右键菜单不算。

快捷键冲突的话，可以在 `chrome://extensions/shortcuts` 修改。

## 已知限制

- 翻译后网页新加载的内容（比如无限滚动的信息流）不会自动翻译。换个目标语言再触发一次会全部重翻。
- 网页里嵌入的 iframe 不翻译（内置翻译只在顶层页面可用）。
- Chrome 设置页、应用商店等特殊页面不能翻译。
- 内置翻译只支持部分语言对，不支持时页面右上角会提示。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 插件配置（Manifest V3） |
| `background.js` | 后台：把图标弹窗、快捷键、右键菜单统一成「切换翻译」，按需把翻译脚本注入当前网页 |
| `content.js` | 注入网页的脚本：找段落、检测语言、调用内置翻译、插入译文、显示提示条 |
| `popup.html` / `popup.js` | 点图标弹出的小窗口：选择目标语言、翻译按钮 |
| `icons/` | 插件图标 |

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `activeTab` + `scripting` | 只在你点图标、按快捷键或用右键菜单时，往**当前标签页**注入翻译脚本；不会在后台读取任何网页 |
| `storage` | 记住你选择的目标语言 |
| `contextMenus` | 添加右键菜单 |
